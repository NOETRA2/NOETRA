# Frozen comparison brief

User subject: **a futuristic sports car**.

Shared concrete interpretation for both runs: an original, unbranded, road-going
two-seat electric sports coupe, low and wide, a wedge nose, four conventional
rubber tires, sculpted wheel arches, silver metallic body, dark wraparound cockpit
glazing, restrained cyan front LED accents, red rear light strip, dark aero
splitter and rear diffuser. No flying/hovering elements, weapons, logos or text.

Target visual envelope for both 3D studies: approximately 4.60 m long, 2.00 m
wide excluding mirrors and 1.16 m high; front/rear axle centers separated by
2.70 m; tire radius 0.355 m. These are modelling targets, not a production vehicle
or engineering-certified design.

Common presentation: dark neutral studio, full car in frame, front three-quarter
camera, soft large lights, identical Blender render resolution/lighting/camera,
same component categories and same procedural topology budget.

Sequence: finish and freeze the baseline image/model first, without invoking
NOETRA for this design; then use the actual local NOETRA engine to model the
same requirements, check explicit constraints, plan and record evidence before
building the second version with the same creative tools. No intentional
degradation of the baseline. Keep separate native models, exports and renders.

This is a single sequential workflow demonstration, not a blinded, seeded or
statistically controlled model benchmark. The agent cannot erase prior context;
image generation is stochastic and the tool exposes no seed control. Appearance
and novelty cannot be proven by Z3 or NOETRA. Report actual differences, including
no improvement, rather than manufacturing a winner.
