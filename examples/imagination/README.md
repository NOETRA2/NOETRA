# Host-driven imagination

Ask the connected host to generate three genuinely distinct structured concepts
for an interface that feels alive without distracting users. Have it provide
each concept's components, requirement IDs, cost estimate, risks and concrete
test plan, with an attributed origin. Pass those candidates to
`noetra.explore_possibilities` for deterministic requirement/cost comparison.

NOETRA ranks supplied candidates; it does not silently call a model or pretend
that a canned idea list is a new generative engine. Originality, subjective
appeal, accessibility and performance require appropriate studies/tests. There
is no VERIFIED aesthetic-preference status.
