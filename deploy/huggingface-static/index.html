RUN THE ACTUAL ENGINE
Try it on your own computer.
Install Node.js 24.11+ in the 24.x line, or Node.js 26+. Then run:
npx --yes noetra@0.1.0-alpha.4 test
npx --yes noetra@0.1.0-alpha.4 demo
Open http://127.0.0.1:7860 for the working local demo. The self-test checks MCP, SQLite and Z3. For durable agent registration, use a project-local installation.
