# NOETRA recorded examples

This free static Space presents **actual, previously captured NOETRA engine
results**. Clicking through these examples does not run the engine or a model.
The full CPU engine can be installed locally from npm:

```sh
npx --yes noetra@0.1.0-alpha.4 test
npx --yes noetra@0.1.0-alpha.4 demo
```

The software is a developer alpha. Formal claims concern supplied integer
premises; evidence records are untrusted observations. Experimental 3D tools
are optional and unfinished. No accuracy percentage is claimed.

No account, API key, uploads, analytics or form submissions are used by this
page. Hugging Face may retain request/network metadata. Source and methods:
https://github.com/NOETRA2/NOETRA
