# Try NOETRA

A small developer-alpha demo of [NOETRA](https://github.com/NOETRA2/NOETRA).
It runs the actual local engine: integer entailment/counterexamples through Z3,
dependency planning and an attributed evidence record. It does not call a model
API or generate meshes. No model downloads, API keys or GPU are required.

Each request uses separate temporary in-memory storage, then discards it. The
application has no analytics or request-body logging. Hosting providers may
retain network/request metadata. The demo accepts only fixed example types
and bounded numbers/booleans; do not send sensitive information.

Formal conclusions concern supplied integer premises, not real-world truth.
The planner's effects/preconditions are supplied. Evidence stays untrusted.

This folder is generated by `node scripts/prepare-space.mjs NEW_FOLDER` after
`npm ci --ignore-scripts && npm run build` in the source repository. Create a
Docker Space in your own account and upload this generated folder's contents.
No hosted demo is claimed until that Space has actually built and been tested.
