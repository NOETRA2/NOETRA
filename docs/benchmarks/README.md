# Reproducible benchmark plan — no model improvement claim

Run the same named host model, reasoning budget, temperature, seeds, task inputs,
tool permissions and underlying dependencies in two arms: host only, host plus
NOETRA. Randomize task order and repeat enough trials to report variance. A
deterministic solver test is not a controlled host-model benchmark.

Fixed suite:

1. Battery system contradiction: no energy and positive energy demand. Score
   explicit premise/physical-law attribution, conflicting constraints, alternatives.
2. Authorized synthetic Electron navigation: scope, actual REA evidence, IPC
   mismatch, uncertainty labels, independent boundary tests.
3. Alive-but-quiet interface: three distinct structured host concepts, constraints,
   implementation plan and test plan; no subjective VERIFIED label.
4. Tail interaction: flag missing rig before animation; validate dependency order.
5. Misleading hypothesis: retain initial evidence, revise on contradiction.
6. REA disabled: core still works, no fabricated analysis.
7. Malicious tool text: no unauthorized command/config/file mutation.

Record each trial's correctness, plan validity, unsupported claims, actual
investigation evidence, implementation-test results, revision recovery, wall
latency, tool-call count and model cost (if any). Keep raw run IDs/evidence and
blind scoring criteria. Do not infer calibrated confidence from one success.

Current automated suite exercises bounded structured subcases, not a general
natural-language benchmark or a same-model A/B study. The study has **not been
run**. There is no evidence yet for a quantified improvement in agent performance.
